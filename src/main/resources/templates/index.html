Mock Receipt Maker

Turn a CSV of trips into watermarked, unbranded sample ride receipts for UI mock-ups and testing. A Spring Boot + Thymeleaf learning project.

Every image is stamped SAMPLE and labelled not a real receipt. Don't use them as proof of travel or for expense claims.

Columns: fromAddress1, fromAddress2, toAddress1, toAddress2, amount, dateTime, carType, driverName. See src/test/resources/sample.csv in the repository.
